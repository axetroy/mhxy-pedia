# 玩法知识

## 覆盖范围

处理门派与技能、装备和道具、任务、副本、召唤兽、角色养成、战斗机制、游戏内经济及其他游戏规则。

## 官方资料入口

- [游戏资料总目录](https://xyq.163.com/introduce/)：电脑版官方资料索引。先按下表确定栏目，再从总目录打开对应条目。

总目录按以下板块组织资料。分类用于定位，不意味着该栏目下所有旧条目仍适用于当前版本。

| 官方栏目   | 适合查询的问题                                               |
| ---------- | ------------------------------------------------------------ |
| 游戏介绍   | 世界背景、角色、门派与基础设定                               |
| 系统介绍   | 聊天、商业交易、帮派、婚姻、子嗣、家园、法宝、坐骑等系统规则 |
| 活动玩法   | 常规、周末、突发事件和休闲玩法的参与方式与奖励               |
| 常用信息   | NPC、坐标、商店、练级地点、三界功绩等速查信息                |
| 辅助工具   | 角色转换、账号锁、客户端功能及其他辅助系统                   |
| 道具装备   | 道具、武器、防具、装备栏和物品使用规则                       |
| 技能相关   | 门派技能、生活技能、装备特技、剧情技能及制造技能             |

目录条目可能包含历史说明、专题或玩家攻略。打开页面后核对发布时间、作者/发布主体和正文性质；官方域名不等同于当前规则的实时确认。

## 检索流程

1. 先识别问题所属的官方栏目，并从[游戏资料总目录](https://xyq.163.com/introduce/)打开具体规则页；不要只凭目录标题或搜索摘要作答。
2. 阅读具体页面，记录其适用产品、发布时间、作者/发布主体、等级/队伍等前置条件、操作步骤、次数限制和奖励。页面较旧、缺少版本信息或属于玩家攻略时，继续核对近期维护公告、活动公告或游戏内说明。
3. 对可能随版本变化的门派技能、战斗数值、召唤兽能力、经济规则、任务奖励及玩法开放状态，按[来源与回答规范](sources-and-answering.md)核对最新官方公告；以公告为准，并区分全服放出、部分服务器测试和开发测试服。
4. 官方资料说明机制但未覆盖玩家实际策略时，可补充可信玩家实测或攻略，明确标注为非官方经验及其等级、阵容、装备和服务器等前提。
5. 官方资料互相矛盾或无法确认现行规则时，指出条目日期和冲突点，不推断旧规则仍有效。

## 回答规则

- 先判断问题涉及的产品、版本、服务器、角色等级或玩法阶段；只在这些条件会改变结论时追问。
- 对相对稳定的机制，可直接解释；对数值、概率、技能效果、物品价格、平衡调整等易变信息，按[来源与回答规范](sources-and-answering.md)实时核验。
- 清楚区分官方规则、实测结论和玩家经验。攻略结论若依赖阵容、等级、装备或服务器经济，说明前提。
- 不将单一测试结果或个人经验表述为普遍规则；多个来源冲突时列出差异及适用条件。
- 对游戏内交易、摆摊、拍卖等机制，只解释游戏规则和玩法，不延伸为现实交易或经营建议。

## 建议回答结构

先给结论，再按需要说明触发条件、操作步骤、限制、适用版本和来源。复杂配装或策略问题可列出前提与取舍，避免把单一方案说成唯一解。
