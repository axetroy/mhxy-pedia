# 维护信息

## 覆盖范围

处理例行维护、临时停服、服务器状态、开服时间、维护延期，以及维护公告中的更新内容。用户问“最近一次”“今天”或“当前维护”时，必须按提问时点重新检索，不能仅凭模型记忆作答。

## 官方公告入口

- [最新维护公告](https://xyq.163.com/news/update/)：查询近期维护公告的首选入口。先在列表中确认最新的相关公告，再打开公告原文核对内容。
- [历史维护公告汇总](https://xyq.163.com/whhz/)：按日期或关键词回查较早的维护公告，也可用于和近期公告交叉核对。

先查最新公告页；用户询问某个历史日期、某次旧更新，或最新列表中找不到目标公告时，再查历史汇总页。两个页面都只作为公告索引，回答前应打开对应公告原文，不能仅凭列表标题或摘要推断维护范围和内容。

## 查询最新维护信息

1. 确认用户问的是哪一款《梦幻西游》产品，以及目标服务器或大区；信息不明确且会影响结论时再追问。
2. 使用当前可用的联网搜索或浏览工具打开[最新维护公告](https://xyq.163.com/news/update/)查找近期公告；若要查历史日期或列表中未找到目标，再打开[历史维护公告汇总](https://xyq.163.com/whhz/)。找到公告后必须打开原文核对。游戏内公告、网易/游戏官方渠道的后续通知可用于确认变更。
3. 核对公告发布时间、维护日期、开始和预计结束时间、维护范围、涉及服务器及延期或补充公告。以中国标准时间（UTC+8）表述；来源未注明时区时，不擅自转换。
4. 如有多个公告或后续变更，以适用于目标服务器且发布时间更新的官方通知为准；同时说明已被更正或延期的信息。
5. 没找到可核实的最新公告时，明确说明检索范围和未确认之处，不用旧公告推测当前状态。

## 输出字段

回答“最新维护”时，按问题需要列出：

- 游戏产品、服务器/大区
- 公告标题、官方来源链接及发布时间
- 维护日期、开始时间、预计结束时间和时区
- 维护影响范围、主要更新内容
- 当前状态，以及延期/补充说明
- 本次检索时间和仍未确认的信息

区分公告计划与实际状态：公告中的预计结束时间不代表服务器已经开放。没有实时状态来源时，不要断言维护已经结束。

## 资料维护约定

本文件维护的是检索和核验方法，不把某一条维护公告固化为永久的“最新信息”。维护公告随时间失效；每次回答都应实时确认。若以后新增公告快照，应单独记录核验日期、适用服务器、官方链接和状态，并明确它只是截至该日期的记录。
