# 版本与活动

## 覆盖范围

处理版本更新、资料片、测试服调整、节日活动、限时玩法、活动奖励、开放条件和活动时间。

## 核验要求

- 对当前版本或正在进行的活动，检索并打开官方更新公告、活动规则或游戏内公告原文。
- 记录公告发布时间、更新/活动生效时间、适用产品、服务器范围及规则版本；区分正式服、测试服和体验服。
- 活动开始时间、结束时间、奖励、参与条件和次数限制可能变动，必须按本次检索确认，不沿用历史活动细节。
- 有后续公告调整规则或时间时，优先采用最新且适用于目标服务器的官方通知，并说明调整内容。
- 仅找到玩家整理或转载时，标注为非官方资料；无法确认的字段明确写出，不自行补全。

## 建议回答结构

先概括更新或活动重点，再列适用范围、时间、参与条件和奖励。为比较版本而引用旧资料时，标明对应版本和来源日期。
